# Dự án Quản lý Công Việc Đơn giản

## Mô tả

### Tính năng chính

Quy trình làm việc nhóm cơ bản : Branch, Pull Request (PR)

Lợi ích:
 + Cô lập (Isolation): Làm việc trên branch riêng không ảnh hưởng dến main hoặc branh của người khác
 + Thử nghiệm: Dễ dàng thử nghiệm ý tưởng mới mà không sợ làm hỏng code chính
 + Code Review: Tạo điều kiện cho việc xem xét code trước khi tích hợp vào main thông qua PR
